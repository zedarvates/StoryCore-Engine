## Tagline

## Short description

Build a production bible, stable characters and locations, ordered scenes, shot prompts, and a continuity report from one idea or short script.

## Long description

StoryCore Harbour turns a concept, synopsis, or short script into a structured visual-production package inside Anna.

Choose the format, duration, language, tone, and audience. Harbour then creates:

- a logline, synopsis, themes, and production bible;
- a coherent visual direction with reusable continuity rules;
- stable character and location identities;
- an ordered scene breakdown;
- shot-by-shot framing, camera intent, action, dialogue, sound direction, and reusable generation prompts;
- a continuity score with explicit warnings;
- a saved project and StoryCore-compatible JSON export.

The core result is independently useful for short films, advertisements, music videos, documentaries, comic/webtoon projects, and social videos.

StoryCore Harbour focuses on planning and continuity. Version 0.1 does not claim to render final images, audio, or video. Heavy local production remains available separately in StoryCore Engine/Desktop.

## What makes a completed run useful

A run is complete only when the generated project:

1. parses as structured JSON;
2. passes the StoryCore Harbour project contract;
3. has valid character, location, scene, and shot references;
4. includes a continuity report;
5. is saved and read back successfully;
6. is shown to the user and can be exported.

Opening the App or pressing the generation button is not treated as a successful completion.

## Key benefits

- **One coherent package:** the story, world, scenes, and shots remain connected.
- **Continuity first:** stable identities and reference checks reduce narrative and visual drift.
- **No separate API key:** the App uses Anna's granted Host APIs.
- **No local production setup:** the core workflow does not require a GPU, ComfyUI, Blender, or StoryCore Desktop.
- **Portable result:** export a versioned `storycore-harbour.project.v1` JSON project.
- **Privacy-conscious design:** no external tracker or developer-operated content backend in version 0.1.
