# 🔬 Technical Deep-Dive — English

## StoryCore Engine: Architecture & End-to-End Pipeline

### Demo Story: *"Little Red Riding Hood in 2048"*

---

### 1. System Architecture Overview

StoryCore Engine is a **multimodal, self-correcting production pipeline** built on three main layers:

```
┌─────────────────────────────────────────────────────────────────┐
│                     ELECTRON DESKTOP APP                         │
│          React 18 + TypeScript UI  ·  FastAPI Backend           │
│               WebSocket (real-time)  ·  REST API                │
└───────────────────────────┬─────────────────────────────────────┘
                            │
┌───────────────────────────▼─────────────────────────────────────┐
│                     STORY ENGINE LAYER                           │
│  LLM/RLM Processing  ·  Script Analysis  ·  Scene Breakdown     │
│  Character Dev  ·  Total Recall (Living Protocol Memory)        │
│  World Aesthetic Registry  ·  Director Rig Metadata             │
└───────────────────────────┬─────────────────────────────────────┘
                            │
┌───────────────────────────▼─────────────────────────────────────┐
│                   PRODUCTION PIPELINE LAYER                      │
│  ComfyUI (8188/8000)  ·  Flux / SDXL / Grok Image              │
│  HunyuanVideo / Wan Video / Seedance  ·  Audio Engine          │
│  Lip-Sync  ·  Quality Check / Auto-Fix  ·  AI Color Grading    │
└───────────────────────────┬─────────────────────────────────────┘
                            │
┌───────────────────────────▼─────────────────────────────────────┐
│                      ADD-ON SYSTEM LAYER                         │
│  Addon Manager  ·  Hooks & Events Bus  ·  Permissions           │
│  Official Addons: Comic · Sensitivity · Translator · Recap…     │
│  NexRealm Marketplace (nexrealm.shop)                           │
└─────────────────────────────────────────────────────────────────┘
```

**Tech stack:**
- **Frontend**: React 18 + TypeScript + Vite (Electron-packaged)
- **Backend**: Python 3.11 + FastAPI + WebSocket
- **AI local**: Ollama / Qwen 2.5-VL / HunyuanVideo / Wan Video
- **Image engine**: ComfyUI (Standard port 8188 or Desktop port 8000)
- **Video**: FFmpeg-based pipeline with circuit breakers
- **Audio**: TTS (emotion-controlled) + auto-composed music + SFX sync

---

### 2. Step-by-Step Pipeline: "Little Red Riding Hood in 2048"

#### Step 1 — Input: Prompt Ingestion
```
Input: "Little Red Riding Hood in 2048"
```
- The **Sequence Plan Wizard** accepts a free-text prompt or a structured JSON project file.
- If free-text: the **Recursive LLM Service (RLM)** expands it, asking itself follow-up questions until a complete narrative is constructed.
- Output: `project.json` + `scene_breakdown.json`

**Example `scene_breakdown.json` structure:**
```json
{
  "scenes": [
    {
      "scene_id": "scene_1",
      "environment": { "type": "megacity-street", "time_of_day": "night", "weather": "rain" },
      "mood": "tense",
      "tension": 0.6,
      "dialogue": [
        { "character_id": "red", "text": "Package 97B. 97th floor. Don't be late.", "emotion": "determined" }
      ],
      "actions": [{ "type": "walk", "description": "Red navigates neon-lit alley" }]
    }
  ]
}
```

---

#### Step 2 — Visual Coherence Sheet (Master Style Lock)

The **Visual Coherence Grid** is computed once per project and injected automatically into every generation call:

```
Visual Coherence Sheet — "Little Red Riding Hood 2048"
───────────────────────────────────────────────────────
STYLE:       Cyberpunk noir / Blade Runner palette
COLORS:      #FF2244 (Red's hoodie), #0A0A1A (shadows), #00F5FF (neon)
LENS:        35mm anamorphic, slight aberration
SENSOR:      Cinematic, grain +20%
ATMOSPHERE:  Rain, fog, neon reflections on wet asphalt
CHARACTER:   Red — teenager, red hoodie, delivery backpack, face partially hidden
FORBIDDEN:   Daylight, warm tones, clean environments
```

This sheet is injected as a **prefix to every ComfyUI prompt**, guaranteeing style lock across all 15–40 shots.

---

#### Step 3 — Image Generation (ComfyUI / Flux)

- **Workflow**: `flux_character_consistency.json` (one of 8 integrated ComfyUI workflows)
- **Models**: Flux Dev (primary) + SDXL (fallback)
- **Memory optimization**: FP8/INT8/FP16/BF16 depending on VRAM available
- **Performance targets**: < 30 sec/image (RTX 4090), < 90 sec (RTX 3060 12GB)
- **Character Consistency Sheets**: Face/Profile/Back reference auto-generated on first character appearance
- **Quality threshold**: SSIM > 0.85, PSNR > 28dB — otherwise auto-fix triggered

**Automatic prompt injection example:**
```
[Master Style] cyberpunk noir, neon city rain, 35mm anamorphic lens, film grain...
[Scene 1 Shot 2] Red enters the elevator, tense expression, neon reflections on her wet hoodie...
[Character Lock] red hoodie teenager, delivery backpack, [CHAR_EMBEDDING_RED]
```

---

#### Step 4 — Audio Engine (Parallel)

Running in parallel with image generation:

| Component | Technology | Output |
|:---|:---|:---|
| **TTS / Voice** | Local TTS (emotion-controlled) | `.wav` per character |
| **Background Music** | Auto-composition (mood-to-score) | lo-fi cyberpunk OST |
| **SFX** | Integrated SFX library | rain, crowd, hum, gunshot |
| **Audio Mastering** | Auto-Ducking + Voice Isolation | Mixed master track |

Audio sync uses scene tension scores from `scene_breakdown.json` to dynamically adjust music BPM and SFX intensity.

---

#### Step 5 — Video Generation (HunyuanVideo / Wan Video)

- **Image-to-Video**: Each generated image becomes a 2–5 second animated clip
- **Camera movements**: Rack focus, slow push-in, drone descent — assigned by AI Shot Composition Engine based on scene mood and tension score
- **Voice-Directed 3D Controls (VDC)**: Objects/NPCs/lighting adjustable via natural language commands midway through generation
- **Motion models**: HunyuanVideo (primary) → Wan Video ATI (high-motion scenes) → Seedance (fallback for realism)

```
Scene 3 — Tension: 0.87
Camera: Low-angle push-in → Subject: Wolf-Corp CEO
Motion: Slow, deliberate — 24fps, 3.2s clip
VFX: Hellation effect + Color Isolation (red hoodie only)
```

---

#### Step 6 — Editing: Automated J-cuts & L-cuts

The **Cinematic Flow** engine applies professional editing rules:
- **J-cut**: Next scene's audio starts 0.5–1.5s before the visual cut
- **L-cut**: Previous scene's audio bleeds 0.5–1s into the next visual
- Selection logic: tension delta between consecutive scenes determines cut type
- **Transition FX Pack**: Crossfade, smash-cut, light-leak defined per genre tag

---

#### Step 7 — Lip-Sync

- Each video clip is matched to its generated audio dialogue
- Lip-sync algorithm maps phonemes to mouth shapes frame-by-frame
- Supports multi-character scenes (character isolation by bounding box)
- Multi-language voice assets supported in same scene

---

#### Step 8 — Quality Check & Auto-Fix

The **Self-Correcting Engine** runs a final pass:

| Check | Method | Threshold |
|:---|:---|:---|
| Visual coherence | SSIM frame comparison | > 0.85 |
| Character consistency | Face embedding similarity | > 0.90 |
| Audio sync drift | Waveform alignment | < 40ms |
| Style drift | Style vector cosine similarity | > 0.80 |

If any check fails → the specific shot is **automatically regenerated** with tighter style constraints. No human intervention required.

---

#### Step 9 — Export

```
Output: final_little_red_riding_hood_2048.mp4
Duration: ~4 min 30 sec
Resolution: 1920×1080 (or 1080×1920 for vertical / 9:16)
Audio: Mixed master (voice + music + SFX)
Metadata: Director Rig metadata embedded (lens, sensor, emotion per shot)
Extras auto-generated:
  ├── recap_teaser.mp4 (YouTube-style narrated teaser)
  ├── comic_edition.pdf (manga-style panels)
  └── translated_japanese.json (Project Translator)
```

#### Étape 2 — Fiche de cohérence visuelle (verrouillage du style maître)

```
Fiche de Cohérence Visuelle — "Le Petit Chaperon Rouge 2048"

STYLE :       Cyberpunk noir / palette Blade Runner
```

Cette fiche est injectée comme **préfixe dans chaque prompt ComfyUI**, garantissant la cohérence de style sur l'ensemble des 15 à 40 plans.

```
[Scène 1 Plan 2] Red entre dans l'ascenseur, expression tendue, reflets néon sur sa capuche mouillée...
[Verrou personnage] capuche rouge adolescente, sac de livraison, [CHAR_EMBEDDING_RED]
```

---

#### Étape 4 — Moteur audio (traitement parallèle)

Exécuté en parallèle de la génération d'images :

| Composant | Technologie | Sortie |
|:---|:---|:---|
| **TTS / Voix** | TTS local (contrôle émotionnel) | `.wav` par personnage |
| **Musique de fond** | Auto-composition (humeur → partition) | OST lo-fi cyberpunk |

---

#### Étape 5 — Génération vidéo (HunyuanVideo / Wan Video)

- **Image-to-Video** : Chaque image générée devient un clip animé de 2 à 5 secondes
- **Mouvements de caméra** : Rack focus, slow push-in, descente drone — assignés par l'AI Shot Composition Engine selon l'humeur et le score de tension de la scène
- **Voice-Directed 3D Controls (VDC)** : Objets, PNJ et éclairage ajustables via commandes en langage naturel en cours de génération
- **Modèles de mouvement** : HunyuanVideo (primaire) → Wan Video ATI (scènes haute cinétique) → Seedance (fallback réalisme)

```

```

---

#### Étape 6 — Montage : J-cuts et L-cuts automatiques

Le moteur **Cinematic Flow** applique les règles de montage professionnel :
- **J-cut** : L'audio de la scène suivante démarre 0,5 à 1,5 s avant la coupe visuelle
- **L-cut** : L'audio de la scène précédente déborde de 0,5 à 1 s dans le plan suivant
- Logique de sélection : le delta de tension entre scènes consécutives détermine le type de coupe
- **Transitions FX Pack** : Fondu enchaîné, smash-cut, light-leak définis par tag de genre

---

#### Étape 7 — Lip-Sync

- Chaque clip vidéo est aligné avec le dialogue audio correspondant
- L'algorithme de lip-sync mappe les phonèmes aux formes de bouche image par image
- Supporte les scènes multi-personnages (isolation par bounding box)
- Assets vocaux multi-langue dans la même scène

---

#### Étape 8 — Contrôle qualité & Auto-correction

Le **Moteur auto-correctif** exécute une passe finale :

| Vérification | Méthode | Seuil |
|:---|:---|:---|
| Cohérence visuelle | Comparaison SSIM frame à frame | > 0,85 |
| Cohérence personnage | Similarité face embedding | > 0,90 |
| Dérive sync audio | Alignement forme d'onde | < 40 ms |
| Dérive de style | Similarité cosinus vecteur style | > 0,80 |

En cas d'échec → le plan spécifique est **automatiquement régénéré** avec des contraintes de style plus strictes. Aucune intervention humaine requise.
