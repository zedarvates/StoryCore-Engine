Official WordPress plugin to link your site with StoryCore Engine and the NexRealm Marketplace.

== Description ==

StoryCore Engine is the self-correcting multimodal production pipeline. This plugin allows you to easily integrate StoryCore links into your WordPress site.

Features:
* Link to official documentation and repository.
* Link to NexRealm Marketplace for assets and add-ons.
* Customizable shortcodes for easy integration.

== Installation ==

1. Upload the `storycore-engine` folder to the `/wp-content/plugins/` directory.
2. Activate the plugin through the 'Plugins' menu in WordPress.
3. Go to StoryCore menu to see links and shortcodes.

== Shortcodes ==

`[storycore_links]`

Attributes:
* `style`: "button" or "list" (default: "button")
* `show_website`: "yes" or "no" (default: "yes")
* `show_marketplace`: "yes" or "no" (default: "yes")
