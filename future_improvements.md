# Future Improvements – StoryCore Engine ## 1. Overview StoryCore Engine is evolving toward a **native integration of open-source tools** (Blender, Krita, ComfyUI) assisted by LLMs to accelerate anime-style and hybrid 2D/3D animation pipelines while preserving artistic control and quality. ## 2. What Has Already Been Implemented ### 2.1 Backend AI Services - **Video Generation**: `backend/ai_video_service.py`, `backend/ai_creative_service.py` - **Audio & Lip-sync**: `backend/ai_audio_service.py`, `backend/lip_sync_api.py` - **Workflow Orchestration**: `backend/ai_workflow_orchestrator.py`, `backend/prompt_composer.py` - **Performance & Caching**: `backend/cache_service.py`, `backend/rate_limiter.py` ### 2.2 Integration Hooks - **Add-on Structure**: `addons/official/`, `addons/community/`, `addons/templates/` - **ComfyUI Support**: `comfyui_portable/`, `comfyui_download_zone/` - **Blender Bridge**: `blender_bridge/`, `blender_projection/` - **N8N Automation**: `backend/n8n_service.py`, `backend/n8n_api.py` ### 2.3 Demo & Testing - **Production Demos**: `demo_lipsync_production.py`, `demo_character_creation_full.py` - **Test Scripts**: `test_upscale.py`, `test_scene_to_3d_set.py`, `test_rlm_parallel.py` - **Pipeline Tests**: `complete_pipeline_test/` ### 2.4 Infrastructure - **Project Management**: `backend/project_api.py`, `backend/project_builder.py` - **Database**: `backend/database.py`, `backend/database_models.py` - **CLI Tools**: `cli/`, `backend/cli_api.py` - **Frontend UI**: `creative-studio-ui/src/components/workspace/ProjectDashboardNew.tsx`, `creative-studio-ui/src/sequence-editor/SequenceEditor.tsx` ### 2.5 Analysis These components provide isolated capabilities but lack: - **Cohesive end-to-end pipelines** (e.g., script → scene → render) - **Standardized data exchange formats** (e.g., SLS, SCG, SSD, SAPF, SRP) - **Native UI panels** within Blender/Krita/ComfyUI - **LLM-driven procedural generation modules** - **Integrated workflow automation** ## 3. Vision Summary - **Native connectors** for Blender, Krita, and ComfyUI. - **Procedural systems** powered by LLMs (SceneBuilder, CameraDirector, PlateComposer, RenderBrain). - **Hybrid anime pipeline** that stitches together storyboard, 3D blocking, rendering, and AI stylization. - **Standardized formats** (SLS, SCG, SSD, SAPF, SRP) to give StoryCore a professional identity. - **Roadmap** that delivers incremental, GitHub-ready milestones. ## 4. Concrete Implementation Ideas ### 4.1 Native Connectors #### Blender Add-on (`addons/official/blender/`) - **Panel Integration**: StoryCore tab in Blender's UI - **Scene Import**: Direct import of SSD (StoryCore Scene Descriptor) files - **Camera Placement**: Auto-placement based on SCG (StoryCore Camera Grammar) rules - **2D/3D Rig Generation**: SLS-compliant layer hierarchies and rig setups - **Plate Management**: Parallax layers, fog, FX using SRP conventions - **Export Passes**: Depth, normal, segmentation masks in ComfyUI-ready formats #### Krita Plugin (`addons/official/krita/`) - **Storyboard Generation**: Convert scripts → storyboard panels via LLM - **Layer Organization**: Auto-tagging per SLS (lineart, flat, shadow, highlight) - **Pass Export**: Multi-pass export (lineart/flat/shadow/background) to ComfyUI - **AI Variation Import**: Browse and import generated variations directly #### ComfyUI Workflows (`workflows/anime_optimized/`) - **Frame Generation**: Anime-style diffusion with character consistency - **Interpolation**: Frame blending for smooth motion - **Upscaling**: 2x/4x upscale with detail preservation - **Technical Pass Processing**: Depth-aware stylization, segmentation-guided rendering ### 4.2 Procedural Systems Assisted by LLMs | Module | Responsibility | Implementation File | |--------|-----------------|----------------------| | **SceneBuilder** | Generates technical scene descriptions, proposes assets, builds ready-to-use Blender scenes. | `backend/scene_composition_service.py` + new `backend/scene_builder_llm.py` | | **CameraDirector** | Suggests camera movements, creates camera paths, adapts style (anime, cinematic, handheld). | `backend/camera_angle_service.py` + new `backend/camera_director_llm.py` | | **PlateComposer** | Organizes layers, proposes atmospheric FX, builds parallax setups. | `backend/plate_composer_service.py` (new) | | **RenderBrain** | Selects optimal render passes, prepares ComfyUI exports, optimizes render time. | `backend/render_brain_service.py` (new) | ### 4.3 Hybrid Anime Pipeline (2D/3D + AI) ``` 1. Storyboard in Krita (SLS layers) ↓ Export: storyboard.ssd + SLS package 2. 3D blocking in Blender (auto-import SSD) ↓ CameraDirector generates camera paths 3. PlateComposer sets up parallax + plates ↓ Export: scene.blend + SRP config 4. Render technical passes (depth, normal, masks) ↓ RenderBrain optimizes settings 5. Stylization / interpolation in ComfyUI ↓ Prebuilt workflow with SSD metadata 6. Manual refinements in Krita (import passes) 7. Automated final assembly (backend/post_production_api.py) ``` ### 4.4 StoryCore Standardization #### StoryCore Layer Standard (SLS) ```json { "version": "1.0", "layers": [ { "id": "lineart_main", "type": "lineart", "source": "krita", "blend_mode": "normal" }, { "id": "flat_color_main", "type": "flat", "source": "ai_generated", "blend_mode": "multiply" }, { "id": "shadow_soft", "type": "shadow", "source": "comfyui", "blend_mode": "multiply" } ] } ``` #### StoryCore Camera Grammar (SCG) ```yaml camera_style: anime_wide movement: - type: pan duration: 2.5s easing: ease_in_out - type: zoom factor: 1.2 duration: 1.0s focal_length: 35mm sensor_size: "super35" ``` #### StoryCore Scene Descriptor (SSD) ```json { "scene_id": "sc_001", "title": "Confrontation", "duration": 30.0, "assets": ["char_hero", "char_villain", "env_ruins"], "shots": [ { "shot_id": "sh_001", "start_time": 0.0, "end_time": 5.0, "camera": "scg_001", "plates": ["bg_ruins", "fg_debris"] } ] } ``` #### StoryCore Asset Pack Format (SAPF) ``` asset_pack/ ├── manifest.json (SAPF metadata) ├── characters/ │ └── hero/ │ ├── model.blend │ ├── textures/ │ └── rigs/ ├── environments/ │ └── ruins/ │ ├── model.blend │ └── materials/ └── plates/ └── parallax_layers/ ``` #### StoryCore Render Pipeline (SRP) ```yaml render_engine: "cycles" samples: 256 denoise: true passes: - "diffuse" - "glossy" - "transparent" - "z" - "normal" - "object_index" comfyui_workflow: "anime_upscale_workflow.json" output_format: "exr" ``` ## 5.
