Option 1: Redémarrage Simple (Recommandé)
==========================================

1. Arrêter l'application:
   → Appuyer sur Ctrl+C dans le terminal où l'app tourne
   → Ou fermer le terminal

2. Redémarrer l'application:
   npm run dev

3. Attendre que l'application démarre:
   → Vite devrait afficher "Local: http://localhost:5173/"
   → Ouvrir le navigateur à cette adresse


Option 2: Redémarrage avec Nettoyage du Cache
==============================================

1. Arrêter l'application (Ctrl+C)

2. Nettoyer le cache:
   npm run clean
   
   OU manuellement:
   rmdir /s /q node_modules\.vite
   rmdir /s /q creative-studio-ui\node_modules\.vite
   rmdir /s /q dist
   rmdir /s /q creative-studio-ui\dist

3. Redémarrer:
   npm run dev


Option 3: Redémarrage Complet (Si problèmes)
=============================================

1. Arrêter l'application (Ctrl+C)

2. Nettoyer complètement:
   rmdir /s /q node_modules
   rmdir /s /q creative-studio-ui\node_modules
   rmdir /s /q dist
   rmdir /s /q creative-studio-ui\dist

3. Réinstaller les dépendances:
   npm install

4. Redémarrer:
   npm run dev

Option 4: Démarrage Complet (Front + Back) - RECOMMANDÉ
=====================================================

Pour que toutes les fonctionnalités (création de personnages, etc.) fonctionnent, vous devez lancer le Frontend ET le Backend.

1. Lancer le Backend (API Python):
   Ouvrir un premier terminal at à la racine du projet:
   python backend/main_api.py
   (Attendre le message: "INFO: Application startup complete")

2. Lancer le Frontend (Vite):
   Ouvrir un second terminal:
   cd creative-studio-ui
   npm run dev

3. Accéder à l'application:
   http://localhost:5173/

┌──────────────────────────────────────────────────────────────────────────────┐
│ 🐛 RÉSOLUTION DE PROBLÈMES                                                  │
└──────────────────────────────────────────────────────────────────────────────┘

Problème: "npm run dev" ne fonctionne pas
Solution: Vérifier que vous êtes dans le bon répertoire
  cd creative-studio-ui
  npm run dev

Problème: Erreurs de compilation TypeScript
Solution: Nettoyer et réinstaller
  rmdir /s /q node_modules
  npm install
  npm run dev

Problème: Port 5173 déjà utilisé
Solution: Tuer le processus ou utiliser un autre port
  netstat -ano | findstr :5173
  taskkill /PID [PID_NUMBER] /F
  
  OU changer le port dans vite.config.ts:
  server: { port: 5174 }

Problème: Modifications non visibles
Solution: Vider le cache du navigateur
  → Ctrl+Shift+R (hard refresh)
  → Ou ouvrir en mode incognito
