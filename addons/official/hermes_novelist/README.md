# Hermes Novelist Addon

This addon integrates the **NousResearch AutoNovel** pipeline into StoryCore.

## Features

- **Phase 1: Foundation**: Generates World Bible, Character Registry, and Chapter Outline from a simple seed.
- **Phase 2: Drafting**: Sequential chapter writing with built-in Anti-Slop and Anti-Pattern filters.
- **Phase 3: Revision**: Automated revision briefs and adversarial editing concepts.

## Usage

1. Open the **Hermes Novelist Wizard** from the StoryCore Menu.
2. Provide a **Seed Concept**.
3. Run the **Foundation** phase to generate your story bible.
4. Start **Drafting** chapters sequentially.
