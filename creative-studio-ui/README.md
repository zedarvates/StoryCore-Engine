# 🎨 Creative Studio UI

This directory contains the React-based user interface for the StoryCore Engine.

## Structure

- `src/` - Main source code
- `components/` - Reusable UI components
- `pages/` - Page-level components
- `services/` - API and data services
- `assets/` - Static assets (images, icons, etc.)

## Development

To run the UI locally:

```bash
cd creative-studio-ui
npm install
npm start
```

## Integration

The UI connects to the StoryCore Engine backend via REST API and WebSocket for real-time updates.

## Dependencies

- React 18+
- TypeScript
- Tailwind CSS
- Various UI libraries for specific components
