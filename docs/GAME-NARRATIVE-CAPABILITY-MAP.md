# StoryCore — Game Narrative Capability Map

Status: commercial taxonomy proposal. Capability status must be reconciled against repository evidence before publication.

## Customer outcomes
- **Game Lore Builder** — world history, cultures, factions, beliefs, chronology and lore structure.
- **Story Builder** — story structure and narrative arcs.
- **Character Builder** — characters, motivations, relationships and development.
- **Act Builder** — acts, dramatic progression, turning points and transitions.
- **Scene Builder** — structured scenes for playable/cinematic/narrative use.
- **Quest Builder** — quests, branches, objectives, conditions and outcomes.
- **Dialogue Builder** — dialogue structures, variants and conditions.
- **Campaign Builder** — coordinated long-form campaign structure.
- **World Story Builder** — connect lore, places, factions, events and quests.
- **Story-to-Game** — transform structured narrative into game-oriented content contracts where adapters are proven.
- **Lore & Quest Checker** — detect contradictions, chronology/reference issues, broken dependencies and uncovered assumptions where evidence supports the check.

## Internal model
Idea/notes/wiki -> Story DNA (EXPERIMENTAL contract) -> lore/timeline/entities/relationships -> arcs -> acts -> scenes -> quests/dialogues -> target adapters.

This is a target composition, not a claim that every arrow is already implemented.

## Publication rule
Each outcome must be labelled ESTABLISHED / EXPERIMENTAL / PROPOSED based on exact StoryCore code/tests/docs. Do not infer implementation from filenames, issue titles or this commercial taxonomy.
