A local‑first AI pipeline that generates coherent images, videos, stories, dialogues, and spatial audio from an augmented storyboard.

## Pipeline

```
Storyboard (texte) → Augmentation IA
  ├─ Images → Stable Diffusion / ComfyUI
  ├─ Vidéos → Animation pipeline
  ├─ Dialogues → LLM script generation
  └─ Audio spatial → Spatial audio rendering
       ↓
  Output cohérent (narration + visuels + son)
```

## Features

- **Narrative continuity** — Personnages, lieux et objets cohérents entre scènes
- **Prompt engineering** — Prompts structurés pour génération cohérente
- **Audio spatial** — Audio spatialisé automatiquement
- **Reproductible** — Workflow reproductible pour production rapide

## Intégration Hnoss

StoryCore Engine s'intègre avec le pipeline Hnoss pour la création multimédia :
```
StoryCore → hnoss pipeline → YouTube / Web / VR
```
